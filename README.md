# CMPS3160 - Fall 2026 Final Project

## By Dylan Sawransky and Martin Rosales

## Project Topic: Socioeconomic Contributors of Chronic Disease in U.S. Counties

### 📌 Project Overview
This project investigates which county-level socioeconomic conditions predict chronic disease prevalence across approximately 3,100 U.S. counties. By analyzing health and socioeconomic data, we aim to determine whether key factors—such as education, insurance coverage and healthcare access—retain significant explanatory power for chronic disease prevalence after controlling for median household income and urban/rural status.

### ❓ Key Research Question
*Does any socioeconomic predictor retain significant explanatory power for chronic disease prevalence after controlling for median household income and rural/urban status?*
